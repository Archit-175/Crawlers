# Web Wonders — Crawlers (original project history)

As the team leader of this incredible journey, I am extremely proud to share that our project, **Crawlers**, has won first place in the Web Wonders competition! 🎉

Crawlers is an interactive website designed to foster forestry exploration and raise environmental awareness. This project wouldn't have been possible without the dedication and hard work of our amazing team: **Dev Shrut Jain, Nilang Bhuva, and Suhani Acharya**.  
A special thank you to our mentors **Darshan Vekariya, Lavanya Pinjarkar, and Saketh Kanuri** for their invaluable guidance.

---

## 🔑 Key Features

- 🌍 **World Tour:** Take a virtual journey across 7 countries—India, USA, Canada, Russia, China, Australia, and Brazil. Each region offers immersive content on iconic forests, enriching the experience with education and wonder.
- ✍️ **Dynamic Blog Section:** A user-driven blog space where users can contribute their thoughts and instantly see their posts, creating a collaborative platform for environmental discussions.
- 🌱 **Tree-Planting Requests:** Users can request a tree to be planted on their behalf, enabling direct contributions to environmental preservation.
- 💼 **Job Applications:** Interested users can apply for jobs related to forestry and environmental conservation, making it a portal for both education and career opportunities.
- 📸 **Gallery Section:** A visually engaging section with vibrant forest images that showcase nature’s beauty from around the world.
- 🧠 **Quiz Section:** Interactive quizzes that test users’ knowledge about forests and environmental conservation.

---

## 🌐 Tech Stack

Built with **HTML, CSS, NodeMailer, MongoDB, JavaScript, and cloud storage**, Crawlers offers a seamless experience across devices, enhancing user engagement with dynamic, interactive elements.

## ⚡ Getting Started

Because this is a static site, no build step is required.

1. Clone the repository.
2. Open `index.html` in a browser, or serve the folder with a local static server for best results.

Example with Python:

```bash
cd /path/to/Crawlers
python3 -m http.server 8000
```
Then visit [http://localhost:8000](http://localhost:8000).
